# Pre-1.0 technical audit — 2026-08-23

## Purpose and decision boundary

The code-level half of launch readiness (#154): what a reviewer owes the
binary before #24 signs it and #22 describes it. The ticket named fourteen
findings; every one was re-verified against `main` @ `67cfb8b` before a line
changed, and the verdicts below override the ticket where they differ. Four
things the ticket missed were treated as findings of the same rank. Store
admin, listings, the website, macOS distribution (#14) and the two findings
the ticket filed rather than fixed stay out.

Evidence was gathered on the iPhone 17 simulator, the Pixel 10 emulator, a
physical iPhone 17 (iOS 26.6, `app.golem.qa` with real MLX) and a physical
OnePlus 12R (Android 16, `app.golem.qa` with real llama.cpp), plus the built
production Android artifacts. No production flavor was installed on a phone.
Device identifiers, paths and pre-existing chat contents are excluded.

## Result summary

Fourteen findings: ten fixed as described, three fixed on a corrected
diagnosis (3, 4, 13), one re-decided by the owner (7). Four misses fixed
alongside. One test file removed, seven single test cases added, no new test
files. Branch gate green; every device row below passed.

## Dispositions

**1 — privacy manifest. Fixed.** `ios/Runner/PrivacyInfo.xcprivacy`, a Runner
resource, declares the DiskSpace category with reasons `85F4.1` (shown to
the user) and `E174.1` (download preflight). The ticket's line numbers were
off by two; the binary's imports (`volumeAvailableCapacityForImportantUsage`,
`volumeTotalCapacity`) were the proof. macOS has no such rule and gets none.
Evidence: the file sits at the root of the built `Runner.app` on both the
simulator and the iP17 install; `platform_assets_test` pins it.

**2 — `CFBundleName`. Fixed on iOS;** it resolves `$(GOLEM_DISPLAY_NAME)`
like the display name (built bundles read `Golem QA`). The worse sibling —
macOS ships as `golem_flutter.app` — is #14's, and is recorded there.

**3 — iOS floor. Fixed, on a different diagnosis.** The MLX carrier is not
linked at launch; Flutter's native-asset pipeline `dlopen`s it at the first
`@Native` call, which is the launch probe, and that failure is not an
`InfernoException`, so an iOS 15 or 16 phone would have launched and died
rather than been refused. The carrier's own `minos 17.0` (confirmed with
`otool` on the device build) is the technical minimum; the owner chose the
current major instead — `IPHONEOS_DEPLOYMENT_TARGET` is 26.0 in all twelve
configurations, with iOS 27 weeks away and every phone above the memory floor
already on 26. ADR 0016 records it; ADR 0003, ADR 0007 and `device_floor.md`
now name the per-platform artifact and the right floor.

**4 — teardown wait. Half the claim was wrong; the half that stood is fixed.**
llama.cpp already aborts a load through its progress callback and a prefill
mid-graph through ggml's abort callback, so its join was bounded all along.
MLX polled cancellation only in its token loop; it now checks before and
after the container load, per image in preparation, and before prefill, and
reports a pre-decode cancel the way llama does. The library's own prefill
stays unpolled — that bound is one prefill — and the join stays unbounded on
purpose: a timed wait would free the callback trampoline under a straggling
task, which is the #124 abort. Evidence: OnePlus, five predictive-back exits
during prefill of a ~150-token prompt with Gemma 4 E2B GGUF — the app left
the foreground every time, the crash buffer and dropbox stayed empty. iP17,
Gemma 4 E2B MLX: a ~120-token prefill completed faster than one automation
round-trip (< 2 s), Stop mid-decode took effect within one, a background
and resume mid-generation kept streaming, and a kill mid-stream left no
crash report; the relaunch read the history back and answered `Tokyo` at
31.7 tok/s.

**5 and 6 — corrupt chat store. Fixed.** Conversations decode one by one; a
quarantined file or a dropped conversation hydrates with `recovered`, which
skips the attachment sweep until the next successful save and shows a
dismissible notice. Enum leaves in every store (`ArtifactPhase`,
`RuntimePhase`, `ThemeSetting`, `ResponseStyle`, `ModelEngine`) fall to a
default instead of an `ArgumentError`; an unparsable custom model drops
alone. The sharper framing the ticket missed: an I/O error on the chat file
threw and kept the pictures, so only corruption ever reached the sweep.
Evidence: simulator, `app.golem.qa` — a store with one unreadable
conversation hydrated the other and showed the notice with the attachment
intact; a file of garbage bytes was renamed `.corrupt`, the notice showed,
and the attachment survived. Three unit cases pin decode, sweep and banner.

**7 — backups. Re-decided.** Attachments in backup was ADR 0004's recorded
choice, not a leak; the gap the ticket missed was Android's 25 MB Auto
Backup quota, which a few attached PNGs exceed, after which nothing backs
up. The owner chose the strict posture: every store is out. iOS and macOS
mark both storage roots excluded at every launch; Android sets
`allowBackup="false"` and extraction rules that exclude every domain from
device transfer too (review of PR #155 caught that the switch alone leaves
transfer on for some manufacturers). ADR 0016 records it and
supersedes ADR 0004's paragraph. Evidence: simulator container — both roots
carry `com_apple_backup_excludeItem`; emulator and OnePlus — the new installs
show no `ALLOW_BACKUP` in `pkgFlags` (the older dev install beside them
still does) and `bmgr backupnow` answers "Backup is not allowed".

**8 — privacy copy. Fixed** in thirteen catalogs (Polish already avoided the
claim; French keeps its narrow no-break punctuation, Arabic its terminology).
The sentence now says chatting needs no network, Golem goes online only on
request, and chats stay out of phone backups with Export as the way across.
ADR 0011, which quoted the old sentence as the reason there is no crash
reporter, quotes the new one. Four goldens re-recorded on macOS.

**9 — analyzer. Fixed, with ADR 0017.** `strict-casts` and
`strict-raw-types` report nothing on this codebase; `unawaited_futures` and
`avoid_dynamic_calls` joined, seven deliberate fire-and-forgets now say so,
and the three lints declined are declined with their counts in the ADR. No
suppression was added.

**10 and 11 — stale docs. Fixed.** The ticket's attributions were issues,
not PRs (#129 → PR #139, #124 → PR #135). `inferno.md` was further behind
than stated — an ABI 3 payload, no Qwen template, no probe, no images, no
load options, no macOS, a teardown story from before #135 — and both planner
skills feed it to agents; it is rewritten. The packaging comment, the README
eval path and the dependency rows (re-derived: the analyzer cap is now `<14`,
so the codegen table is one reviewed `pub upgrade` from resolvable) follow.

**12 — storage probes. Fixed.** Attachments and cache are nullable like free
space; an unreadable bucket is omitted and the headline sums what was read.
The user-facing harm the ticket missed: a failed cache probe printed 0 MB
and disabled Clear cache. The `totalBytes` probe is unread by any surface
and left in place — removing it is a three-host channel change, not an
audit fix.

**13 — `toggleRuntime`. Fixed on a corrected diagnosis.** Its engine calls
were already caught; the residue was four unguarded bookkeeping writes and a
`requireValue`, and a throw there left the Models row on `loading` with the
toggle withheld until a relaunch. The write degrades to the engine's actual
phase, a missing state returns, and anything that still escapes restores the
row before rethrowing.

**14 — test-suite audit. Re-measured**, appended to the 2026-08-15 note:
1,297 tests, 89.7 % line coverage outside the locale tables, 104 goldens all
referenced. The coverage map's seven new zero-unique files are behaviour
suites the goldens only paint and stay; `app_version_test.dart` was the one
redundant file and is folded into the About row's owner.
`artifact_adoption_policy.dart` joined the mutation set with its test in the
command. The 833-mutant run was started in a throwaway worktree at the
start of implementation and was still running when this note was written
(five files complete: `model_activation` 0/25, `model_admission` 2/14,
`device_eligibility` 4/55, `model_speed` 0/22, `response_style_mapping`
0/10 undetected); its full result is recorded below when it lands, or the
deferral stands.

### Missed by the ticket, fixed here

- **`ITSAppUsesNonExemptEncryption`** was absent; `false`, with the reasoning
  (OS HTTPS and SHA-256 integrity hashing only) in ADR 0016.
- **Android backup quota** — folded into 7.
- **The `toggleRuntime` deadlock** — folded into 13.
- **`inferno.md` as agent context** — folded into 11.

### Deferred, with reasons

- macOS `golem_flutter.app` / `PRODUCT_NAME` — #14 (changes `TEST_HOST` and
  the README's binary path).
- `.corrupt` quarantine overwrites an earlier `.corrupt`, and those bytes are
  neither counted nor cleaned — rare, forensic-only, its own small ticket.
- No root `analysis_options.yaml`: `tool/` is lint-free. Own ticket.
- `pubspec` `sdk: ^3.12.2` is a floor, not a pin; #24 sets what the release
  build pins.
